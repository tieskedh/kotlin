versions/hashes. The output directory must not exist. Raw original artifacts:
`D:\CodexTemp\hybrid-owner-research-20260924\kotlin-results`.

## CLR mechanism

`clr/` contains the executed C# sources, runner and preparation-time README.
That README's “not executed” title describes preparation; subsequent results
are in `clr/results/`. Both profiles have six positive mechanism groups and
two expected incompatible-cast groups, plus a distinct CS0453 compile negative.
The proposed `IBoxView` is explicitly public and read-only. This is a hand model,
not generated Kotlin output, a complete projection contract or a performance
benchmark.

```powershell
./clr/Run-Probe.ps1 -OutputDirectory D:/CodexTemp/hybrid-clr-rerun
```

Use an absent/empty output directory and the installed pinned SDK; no downloads
occur. The runner builds three independent assemblies per profile and executes
the profiles serially. Do not overlap it with another Framework lane. Modern
reference assemblies come from the 10.0.0 pack; Framework uses the installed
CLR4 assemblies and records all hashes. Runtime versions are reported separately.

Raw successful artifacts:
`D:\CodexTemp\hybrid-owner-research-20260924\clr-results-verified`.
The initial `clr-results` failed saving output beside the hosting PowerShell
executable. Only the observer path changed, to its own assembly directory;
the successful manifest hashes that corrected source. No CLR semantic failure
was repaired. Binary products and empty successful compile logs remain in the
raw directory rather than being copied into Git.


`-Profiles net48 -Iterations 10000000 -Warmup 1000000 -Samples 7`, the same
`-ArtifactDirectory`, and a fresh `-OutputDirectory`. Do not pass `-IncludeNested`:
the diagnostic covers the shared broad path and unchanged scalar control.
Recreating the frozen compiler products requires the previous archive's
explicit fixture/harness patches and isolated matrix, not these hand models.

Manifests identify original executed Windows bytes and absolute raw paths.
Archived text is newline-normalized and ends with one newline; those presentation
changes do not rewrite the original source/tool/product hashes. No binaries,
compiler caches, runtime packs or extra worktrees are archived here.
